1️⃣ ثبت PM2

افتح CMD مرة واحدة فقط:

npm install -g pm2

2️⃣ روح لمجلد مشروعك
cd D:\xampp\htdocs\710

3️⃣ شغل السيرفر بـ PM2
pm2 start server.js --name scale-app

4️⃣ خليه يشتغل تلقائي مع الويندوز
pm2 startup


هيظهر لك أمر تنسخه وتشغله كـ Administrator
بعدها نفذ:

pm2 save

🎯 النتيجة

✔ يشتغل بدون CMD
✔ يشتغل مع بدء التشغيل
✔ لا يمكن قفله إلا من PM2
✔ أقوى وأأمن حل
✅ الحل الصحيح لتشغيل PM2 مع بدء تشغيل ويندوز
🔹 1️⃣ ثبت pm2-windows-startup

افتح CMD كمسؤول (Run as Administrator) واكتب:

npm install -g pm2-windows-startup

🔹 2️⃣ فعل الخدمة
pm2-startup install


لو طلب تأكيد اضغط Enter.

🔹 3️⃣ احفظ العمليات الحالية
pm2 save

🎯 كده حصل إيه؟

✔ PM2 بقى Windows Service
✔ هيشتغل تلقائي مع بدء الجهاز
✔ بدون CMD
✔ حتى لو حد قفل الجهاز هيشتغل تاني
✔ لو السيرفر وقع هيعيد نفسه تلقائي

🧠 للتأكد إنه تمام

اعمل Restart للجهاز
وبعد ما يفتح اكتب:

pm2 list


لو لقيت scale-app online يبقى تمام 👌

💎 مستوى احترافي أعلى (اختياري)

لو مشروع الميزان شغال 24 ساعة ومهم جدًا
شغله بـ:

pm2 start server.js --name scale-app --restart-delay=5000 --max-memory-restart=300M
pm2 save


ده معناه:

لو حصل Crash يعيد بعد 5 ثواني

لو استهلك ميموري كبيرة يعمل Restart تلقائي
✅ الحل الصحيح

لازم تشغل الأمر من مجلد مشروعك 👇

cd /d D:\XAMPP\htdocs\710


وبعدين نفذ:

pm2 delete scale-app


وبعدين شغله بالإعدادات الاحترافية:

pm2 start server.js --name scale-app --restart-delay=5000 --max-memory-restart=300M


ثم احفظ:

pm2 save

🥈 الطريقة المحلية (من غير إنترنت – داخل الشبكة بس)

لو عايز تفتح المراقبة من الموبايل داخل نفس شبكة الراوتر:

1️⃣ شغل Monitoring Console


cd /d "D:\xampp\htdocs\710"
pm2 monit
pause
/////////////////



🟢 الخطوة 5: أعد تشغيل PM2
pm2 restart scale-app
pm2 save



pm2 stop scale-app



✅ 1️⃣ إيقاف مؤقت (Stop)

ده يوقف السيرفر لكن يفضل موجود في PM2:

pm2 stop scale-app


أو بالـ id:

pm2 stop 0


📌 تقدر ترجعه تاني:

pm2 start scale-app

❌ 2️⃣ حذف السيرفر نهائيًا من PM2

لو عايز تمسحه خالص:

pm2 delete scale-app


بعدها مش هيشتغل تاني إلا لو شغلته يدويًا.

🔥 3️⃣ إيقاف PM2 بالكامل

لو عايز تقفل كل العمليات:

pm2 kill


ده يقفل كل حاجة شغالة تحت PM2.

⚡ 4️⃣ لو مفعّل التشغيل التلقائي مع ويندوز

لو كنت عامل:

pm2 startup


وعايز تمنع التشغيل مع بدء النظام:

pm2 unstartup
pm2 save


pm2 stop scale-app
pm2 stop 0
pm2 delete name
pm2 list
pm2 stop all
pm2 restart all
